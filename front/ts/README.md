## 如何运行示例

电脑已安装 Node.js 时，可以在本目录执行：

```bash
npx --yes --package typescript tsc --version
npx --yes tsx examples/type-safe-api.ts
```

也可以在 [TypeScript Playground](https://www.typescriptlang.org/play) 中粘贴任意代码片段，查看 JavaScript 编译结果和类型提示。

检查综合示例：

```bash
npx --yes --package typescript tsc --project tsconfig.json
```

## 学习方法

1. 先预测一段代码的类型，再把鼠标悬停到变量上验证。
2. 主动打开 `strict`，不要依靠 `any` 绕开问题。
3. 修改示例中的字段或联合成员，观察错误如何沿调用链传播。
4. 类型用于描述真实业务规则。若一个无效状态能被类型表示，优先改进模型。

## 一个最小示例

```ts
type User = {
  id: number;
  name: string;
};

function greet(user: User): string {
  return `你好，${user.name}`;
}

greet({ id: 1, name: "小明" });
// greet({ id: "1", name: "小明" }); // ❌ id 必须是 number
```

TypeScript 在运行前检查传入对象是否符合 `User`，但生成的 JavaScript 中不会保留 `User`。因此，TypeScript 能检查开发期间已知的数据，却不能自动保证接口响应、用户输入等运行时数据可信。
