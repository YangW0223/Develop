# 05. 泛型

## 1. 为什么需要泛型

下面的函数返回传入的值。如果用 `any`，输入和输出之间的类型关系丢失了：

```ts
function identityAny(value: any): any {
  return value;
}

const result = identityAny("hello"); // any
```

泛型用“类型参数”保存这段关系：

```ts
function identity<T>(value: T): T {
  return value;
}

const text = identity("hello"); // "hello"
const count = identity(42);      // 42
```

`T` 是类型变量。调用时编译器通常能推断它，无需写 `identity<string>("hello")`。

## 2. 泛型函数

获取数组第一个元素：

```ts
function first<T>(items: readonly T[]): T | undefined {
  return items[0];
}

const firstName = first(["小明", "小红"]); // string | undefined
const firstId = first([1, 2, 3]);           // number | undefined
```

返回值包含 `undefined`，因为空数组没有第一个元素。泛型不仅复用实现，还保留具体元素类型。

多个类型参数可以表达多个位置之间的关系：

```ts
function pair<K, V>(key: K, value: V): [K, V] {
  return [key, value];
}

const entry = pair("age", 18); // [string, number]
```

## 3. 泛型约束

若实现中需要访问 `.length`，并非所有类型都支持：

```ts
type HasLength = { length: number };

function longer<T extends HasLength>(a: T, b: T): T {
  return a.length >= b.length ? a : b;
}

longer("TS", "JavaScript");
longer([1], [1, 2]);
// longer(1, 2); // ❌ number 没有 length
```

`extends` 在这里表示约束：`T` 至少满足 `HasLength`。

## 4. `keyof` 约束对象的键

```ts
function getProperty<T, K extends keyof T>(object: T, key: K): T[K] {
  return object[key];
}

const user = { id: 1, name: "小明", active: true };

const name = getProperty(user, "name");   // string
const active = getProperty(user, "active"); // boolean
// getProperty(user, "email"); // ❌ email 不是 user 的键
```

这里建立了三重关系：`key` 必须属于对象，返回类型又由具体的 `key` 决定。

## 5. 泛型接口和类型别名

```ts
interface ApiResponse<T> {
  code: number;
  message: string;
  data: T;
}

type User = { id: number; name: string };

const response: ApiResponse<User> = {
  code: 0,
  message: "ok",
  data: { id: 1, name: "小明" },
};
```

同一个响应外壳可以承载用户、商品或分页数据，不需要复制结构。

## 6. 泛型类

```ts
class Store<T> {
  #items: T[] = [];

  add(item: T): void {
    this.#items.push(item);
  }

  all(): readonly T[] {
    return this.#items;
  }
}

const numberStore = new Store<number>();
numberStore.add(1);
// numberStore.add("1"); // ❌
```

## 7. 默认类型参数

```ts
type Result<T, E = Error> =
  | { ok: true; value: T }
  | { ok: false; error: E };

type UserResult = Result<User>;         // 错误默认是 Error
type FormResult = Result<User, string>; // 错误改为 string
```

默认类型适合最常见情况，同时保留定制能力。

## 8. 泛型常见误区

### 没有关系时不要强行使用泛型

```ts
// T 只出现一次，没有建立任何类型关系
function logValue<T>(value: T): void {
  console.log(value);
}

// 更直接
function logUnknown(value: unknown): void {
  console.log(value);
}
```

泛型至少应连接两个位置，或让调用者控制返回/容器类型。

### 不要用断言伪造泛型返回值

```ts
function unsafeCreate<T>(): T {
  return {} as T;
}

const user = unsafeCreate<User>(); // 编译通过，运行值却没有 id、name
```

泛型表示“适用于任意调用者指定的类型”，实现必须真正做到这一点。
