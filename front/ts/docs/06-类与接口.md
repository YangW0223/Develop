# 06. 类、接口与面向对象

## 1. 类的基本类型

```ts
class User {
  readonly id: number;
  name: string;
  private password: string;

  constructor(id: number, name: string, password: string) {
    this.id = id;
    this.name = name;
    this.password = password;
  }

  verifyPassword(input: string): boolean {
    return input === this.password;
  }
}
```

- `public` 是默认可见性，可从任意位置访问。
- `private` 只允许类内部访问，是 TypeScript 的编译期限制。
- `protected` 允许当前类和子类访问。
- `readonly` 只允许在声明处或构造函数中赋值。

构造函数参数属性能缩短代码：

```ts
class Product {
  constructor(
    public readonly id: number,
    public name: string,
    private cost: number,
  ) {}

  profit(price: number): number {
    return price - this.cost;
  }
}
```

## 2. `private` 与 JavaScript 的 `#私有字段`

```ts
class Counter {
  #value = 0;

  increment(): void {
    this.#value += 1;
  }
}
```

`private value` 在编译后可能仍能通过普通属性手段访问；`#value` 是 JavaScript 原生的运行时私有字段。需要真正封装时优先考虑 `#`。

## 3. 接口约束类

```ts
interface Serializable {
  serialize(): string;
}

class Settings implements Serializable {
  constructor(private readonly theme: string) {}

  serialize(): string {
    return JSON.stringify({ theme: this.theme });
  }
}
```

`implements` 检查实例的公开部分是否符合接口，不会自动生成实现，也不会检查类的静态部分。

## 4. 继承与抽象类

```ts
abstract class Shape {
  abstract area(): number;

  describe(): string {
    return `面积：${this.area().toFixed(2)}`;
  }
}

class Circle extends Shape {
  constructor(private readonly radius: number) {
    super();
  }

  area(): number {
    return Math.PI * this.radius ** 2;
  }
}
```

抽象类不能直接实例化，可以同时包含必须由子类实现的方法和共享实现。

## 5. 优先组合，而非复杂继承

继承适合稳定的“是一种”关系。共享能力常可通过组合表达：

```ts
interface Logger {
  log(message: string): void;
}

class ConsoleLogger implements Logger {
  log(message: string): void {
    console.log(message);
  }
}

class OrderService {
  constructor(private readonly logger: Logger) {}

  create(): void {
    this.logger.log("创建订单");
  }
}

const service = new OrderService(new ConsoleLogger());
```

`OrderService` 依赖接口而非具体实现，测试时可以传入内存日志器。组合让依赖关系更直接，也避免多层继承造成的耦合。

## 6. 静态成员与类的两侧

```ts
class IdGenerator {
  static #nextId = 1;

  static next(): number {
    return this.#nextId++;
  }
}
```

`IdGenerator.next()` 属于构造函数本身；实例方法属于 `new IdGenerator()` 得到的对象。`implements` 只检查实例一侧。

可以用构造签名描述“能够创建某种实例的类”：

```ts
interface Named {
  name: string;
}

type NamedConstructor<T extends Named> = new (name: string) => T;

function createNamed<T extends Named>(Ctor: NamedConstructor<T>, name: string): T {
  return new Ctor(name);
}
```

## 7. `this` 类型

链式 API 可以返回 `this`，子类调用时仍保留子类类型：

```ts
class QueryBuilder {
  protected clauses: string[] = [];

  where(clause: string): this {
    this.clauses.push(clause);
    return this;
  }
}
```

回调函数也能显式声明 `this` 参数；该参数只参与类型检查，不会生成 JavaScript 参数：

```ts
function handleClick(this: HTMLButtonElement, event: MouseEvent): void {
  this.disabled = true;
  console.log(event.type);
}
```

## 8. 何时使用类

适合类的情况：对象具有身份、内部状态、生命周期或需要真正的封装。不需要状态和继承时，普通对象、函数与联合类型往往更简单。TypeScript 并不要求所有业务模型都写成类。
