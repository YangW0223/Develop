# 11. 交叉类型与 `&` 操作符

TypeScript 中的 `&` 有两种含义：

1. 出现在类型位置时，表示交叉类型。
2. 出现在值表达式中时，表示 JavaScript 的按位与运算。

## 1. 交叉类型

`A & B` 表示一个值必须同时满足类型 `A` 和类型 `B`：

```ts
type User = {
  id: number;
  name: string;
};

type Timestamp = {
  createdAt: Date;
  updatedAt: Date;
};

type UserWithTimestamp = User & Timestamp;

const user: UserWithTimestamp = {
  id: 1,
  name: "小明",
  createdAt: new Date(),
  updatedAt: new Date(),
};
```

`UserWithTimestamp` 必须拥有两个类型中的全部属性。

## 2. `&` 与 `|` 的区别

```ts
type A = { name: string };
type B = { age: number };

type Union = A | B;
type Intersection = A & B;
```

- `A | B`：满足 `A` 或 `B`，表示多种可能。
- `A & B`：同时满足 `A` 和 `B`，表示能力或约束的组合。

```ts
const union1: Union = { name: "小明" };
const union2: Union = { age: 18 };

const intersection: Intersection = {
  name: "小明",
  age: 18,
};
```

## 3. 为已有类型增加能力

交叉类型经常用于组合可复用能力：

```ts
type Identifiable = {
  id: number;
};

type Serializable = {
  serialize(): string;
};

type Entity = Identifiable & Serializable;

const entity: Entity = {
  id: 1,
  serialize() {
    return JSON.stringify({ id: this.id });
  },
};
```

它也适合描述泛型函数增强后的返回值：

```ts
function withTimestamp<T extends object>(
  value: T,
): T & { createdAt: Date } {
  return {
    ...value,
    createdAt: new Date(),
  };
}

const user = withTimestamp({ id: 1, name: "小明" });

user.name;      // 原对象的属性仍然存在
user.createdAt; // 同时拥有新增属性
```

## 4. 同名属性如何合并

两个类型有同名属性时，该属性必须同时满足两边的类型：

```ts
type A = {
  value: string;
};

type B = {
  value: string | number;
};

type C = A & B;
// C["value"] 是 string
```

`string` 同时满足 `string` 和 `string | number`，因此结果是 `string`。

完全不兼容的属性会产生 `never`：

```ts
type StringValue = {
  value: string;
};

type NumberValue = {
  value: number;
};

type Impossible = StringValue & NumberValue;
// Impossible["value"] 是 string & number，即 never
```

不存在同时是 `string` 和 `number` 的值，所以无法正常构造 `Impossible`。不要用交叉类型强行合并互相冲突的业务模型。

## 5. 原始类型和字面量的交叉

```ts
type Admin = string & "admin";
// "admin"
```

`"admin"` 本来就是 `string` 的子类型，因此交叉结果是更具体的 `"admin"`。

完全不相容的类型会得到 `never`：

```ts
type ImpossibleValue = string & number;
// never

type ImpossibleStatus = "success" & "error";
// never
```

## 6. 与联合类型组合

交叉类型可以和联合类型一起使用：

```ts
type WithId = { id: number };
type User = { name: string };
type Article = { title: string };

type Result = WithId & (User | Article);
```

可以将它理解为：

```ts
type Result =
  | (WithId & User)
  | (WithId & Article);
```

因此下面两个值都合法：

```ts
const user: Result = {
  id: 1,
  name: "小明",
};

const article: Result = {
  id: 2,
  title: "TypeScript 入门",
};
```

联合与交叉混用时，建议添加括号，避免类型关系难以理解。

## 7. 合并函数类型

函数类型也能进行交叉，效果类似函数重载：

```ts
type Formatter =
  & ((value: string) => string)
  & ((value: number) => number);
```

调用者会看到两个调用签名：

```ts
declare const format: Formatter;

const text = format(" hello "); // string
const count = format(1.5);      // number
```

不过，实现这种交叉函数经常需要类型断言。需要编写实际函数时，重载通常更加清晰：

```ts
function format(value: string): string;
function format(value: number): number;
function format(value: string | number): string | number {
  return typeof value === "string"
    ? value.trim()
    : Math.round(value);
}
```

## 8. 与 `interface extends` 的区别

下面两种写法都能扩展对象结构：

```ts
interface User {
  id: number;
}

interface Admin extends User {
  permissions: string[];
}
```

```ts
type User = {
  id: number;
};

type Admin = User & {
  permissions: string[];
};
```

选择建议：

- 清晰、稳定的对象继承关系可优先使用 `interface extends`。
- 临时组合类型、泛型结果和类型运算适合使用 `&`。
- `&` 还能组合联合类型、原始类型和函数类型，适用范围更广。
- 属性冲突时，接口继承一般会直接报错，而交叉类型可能悄悄产生 `never`。

## 9. `&` 不会在运行时合并对象

交叉类型只存在于编译阶段：

```ts
type A = { name: string };
type B = { age: number };
type C = A & B;
```

以上代码不会创建或合并任何对象。真正的运行时合并需要使用对象展开或 `Object.assign`：

```ts
const basic = { name: "小明" };
const detail = { age: 18 };

const user = {
  ...basic,
  ...detail,
};
```

编译器会将 `user` 推断为同时包含 `name` 和 `age` 的对象。

需要注意，运行时对象展开遇到同名属性时，后面的值会覆盖前面的值；交叉类型则要求同名属性的类型同时成立。两者不是完全相同的概念。

## 10. 值表达式中的按位与

当 `&` 出现在运行时代码中时，它是 JavaScript 的按位与：

```ts
const result = 6 & 3;
```

计算过程：

```text
6 = 110
3 = 011
&   010
```

结果是 `2`。按位与常用于检查位标志：

```ts
const READ = 1;   // 001
const WRITE = 2;  // 010
const DELETE = 4; // 100

const permission = READ | WRITE; // 011

if ((permission & WRITE) !== 0) {
  console.log("拥有写权限");
}
```

这里的 `&` 会参与真实计算，与类型位置的交叉类型没有关系。

## 11. 使用建议

- 把 `A & B` 理解为“同时满足”，而不是简单覆盖字段。
- 注意同名属性冲突，它们可能导致 `never`。
- 不要把类型交叉误认为运行时对象合并。
- 复杂对象继承优先考虑可读性更好的 `interface extends`。
- 联合类型和交叉类型混用时使用括号明确关系。
- 高级类型应该减少重复、帮助调用者，而不是单纯追求复杂技巧。

## 12. 练习

1. 定义 `WithId<T>`，为任意对象类型增加只读数字 `id`。
2. 将 `string & ("admin" | "user")` 化简，并解释结果。
3. 尝试合并 `{ status: "success" }` 与 `{ status: "error" }`，观察属性类型。
4. 使用位标志表示读取、写入和删除权限，并编写 `hasPermission` 检查函数。
