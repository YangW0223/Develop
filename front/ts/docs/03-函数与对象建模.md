# 03. 函数与对象建模

## 1. 函数的参数和返回值

```ts
function calculateTotal(price: number, quantity: number): number {
  return price * quantity;
}

const total = calculateTotal(99, 2); // number
```

返回值通常能被推断，但公共函数显式声明返回类型有两个优点：它是清晰的契约，并能防止实现变化意外改变返回结构。

函数表达式可以使用函数类型：

```ts
type Formatter = (value: number) => string;

const formatCurrency: Formatter = value => `¥${value.toFixed(2)}`;
```

## 2. 可选参数、默认参数和剩余参数

```ts
function greet(name: string, prefix = "你好", suffix?: string): string {
  return `${prefix}，${name}${suffix ?? ""}`;
}

greet("小明");
greet("小明", "早上好", "！");
```

`suffix?: string` 在函数内部是 `string | undefined`。默认参数 `prefix` 在调用时也可以省略，但函数内部一定是 `string`。

剩余参数收集任意数量的同类参数：

```ts
function sum(...values: number[]): number {
  return values.reduce((total, value) => total + value, 0);
}
```

## 3. 对象类型与可选、只读属性

```ts
type Product = {
  readonly id: number;
  name: string;
  description?: string;
  price: number;
};

const keyboard: Product = {
  id: 1,
  name: "机械键盘",
  price: 299,
};

keyboard.name = "无线机械键盘";
// keyboard.id = 2; // ❌ readonly 属性不能重新赋值
```

`readonly` 也是浅层的：若只读属性指向对象，该对象内部仍可能被修改。

## 4. `type` 与 `interface`

两者都能描述对象：

```ts
interface User {
  id: number;
  name: string;
}

type Product = {
  id: number;
  name: string;
};
```

接口支持继承和声明合并：

```ts
interface Admin extends User {
  permissions: string[];
}
```

类型别名能表达联合、元组、原始类型别名等更广泛结构：

```ts
type Id = string | number;
type Point = [number, number];
```

实用约定：对象公共契约可优先 `interface`；联合类型和类型运算使用 `type`。不必机械统一，团队保持一致即可。

## 5. 交叉类型

交叉类型将多个类型组合起来：

```ts
type Timestamped = {
  createdAt: Date;
  updatedAt: Date;
};

type Article = {
  id: number;
  title: string;
} & Timestamped;
```

如果同名属性互相冲突，结果可能成为 `never`，因此不要用交叉类型强行合并不兼容模型。

## 6. 索引签名与 `Record`

当对象的键在运行前不完全确定：

```ts
type Scores = {
  [studentName: string]: number;
};

const scores: Scores = { 小明: 90, 小红: 95 };
```

也可以写成：

```ts
type Scores = Record<string, number>;
```

如果键的集合是有限的，应让它更精确：

```ts
type Subject = "math" | "english";
type Report = Record<Subject, number>;

const report: Report = { math: 90, english: 88 };
```

## 7. 函数重载

当返回类型取决于输入形式时，可以使用重载：

```ts
function parse(value: string): number;
function parse(value: number): string;
function parse(value: string | number): number | string {
  return typeof value === "string" ? Number(value) : String(value);
}

const count = parse("42"); // number
const text = parse(42);    // string
```

前两行是调用签名，最后一个是实现签名。若只需要表示“参数是多种类型之一，返回值不随之变化”，普通联合类型更简单。

## 8. 结构化类型系统

TypeScript 主要关心对象“有什么”，而不是“叫什么”：

```ts
type Named = { name: string };

const student = { id: 1, name: "小明", grade: 3 };

function printName(value: Named): void {
  console.log(value.name);
}

printName(student); // 合法：student 至少拥有 name: string
```

但直接传对象字面量会触发额外属性检查，帮助发现拼写错误：

```ts
// printName({ name: "小明", nmae: "拼错了" }); // ❌ 多余属性
```

## 9. `satisfies`：验证但保留精确类型

```ts
type Route = {
  path: string;
  auth: boolean;
};

const routes = {
  home: { path: "/", auth: false },
  profile: { path: "/profile", auth: true },
} satisfies Record<string, Route>;

routes.profile.path; // 保留具体对象的键提示
```

与 `as Record<string, Route>` 不同，`satisfies` 会检查结构，同时尽量保留表达式自身的精确信息。
