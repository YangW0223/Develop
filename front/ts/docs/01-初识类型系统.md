# 01. 认识 TypeScript

## 1. TypeScript 解决什么问题

JavaScript 是动态类型语言，同一个变量在运行期间可以保存不同种类的值：

```js
let price = 100;
price = "免费";
```

语法没有问题，但后续执行 `price.toFixed(2)` 时会在运行阶段报错。TypeScript 在 JavaScript 之上增加静态类型检查，让许多问题在编辑器或构建阶段提前暴露：

```ts
let price = 100;
// price = "免费"; // ❌ Type 'string' is not assignable to type 'number'

price.toFixed(2); // 安全，price 被推断为 number
```

TypeScript 的核心价值包括：

- 更早发现类型不匹配、拼写错误和空值问题。
- 编辑器可以提供跳转、补全和可靠重构。
- 类型本身能够表达函数和业务数据的使用方式。
- 大型项目中，修改一处模型后，编译器会指出受影响的位置。

## 2. TypeScript 与 JavaScript 的关系

TypeScript 是 JavaScript 的超集：合法的 JavaScript 通常也是合法的 TypeScript。浏览器和 Node.js 默认运行的是 JavaScript，因此 `.ts` 文件通常需要先经过编译：

```text
源代码 .ts → 类型检查 → 移除类型语法 → JavaScript .js → 运行
```

例如：

```ts
const add = (a: number, b: number): number => a + b;
console.log(add(1, 2));
```

编译后大致是：

```js
const add = (a, b) => a + b;
console.log(add(1, 2));
```

`number` 等类型信息被移除了。这叫作“类型擦除”。因此下面的判断不可行：

```ts
type User = { name: string };
// if (value instanceof User) {} // ❌ User 只是类型，不是运行时的值
```

## 3. 类型检查不等于运行时校验

开发者声明接口响应是 `User`，不代表服务器一定返回正确数据：

```ts
type User = { id: number; name: string };

const response = await fetch("/api/user/1");
const user = (await response.json()) as User;
```

`as User` 只是告诉编译器“请相信我”，不会检查真实响应。边界数据应在运行时校验，验证后再进入类型安全的内部代码：

```ts
function isUser(value: unknown): value is User {
  if (typeof value !== "object" || value === null) return false;
  const record = value as Record<string, unknown>;
  return typeof record.id === "number" && typeof record.name === "string";
}
```

后面的章节会解释 `unknown`、类型谓词和断言。

## 4. 编译器和执行工具

- `tsc`：官方 TypeScript 编译器，负责检查并生成 JavaScript。
- `tsx`：适合开发和学习时直接执行 TypeScript。
- Vite、Webpack 等构建工具：常用于前端项目，但有些只转译、不做完整类型检查，仍应单独运行 `tsc --noEmit`。

常用命令：

```bash
npx tsc --init             # 生成 tsconfig.json
npx tsc --noEmit           # 只检查，不输出 JavaScript
npx tsc --watch            # 文件变化时持续检查
npx tsx example.ts         # 直接运行示例
```

## 5. 第一个编译错误

```ts
function formatPrice(price: number, currency = "CNY"): string {
  return `${currency} ${price.toFixed(2)}`;
}

formatPrice(19.9);        // "CNY 19.90"
formatPrice(19.9, "USD"); // "USD 19.90"
// formatPrice("19.9");    // ❌ 参数类型错误
```

这里包含三种信息：

- `price: number` 是显式参数类型。
- `currency` 从默认值推断为 `string`。
- `: string` 声明函数返回字符串。

类型标注应放在边界和公共接口上；局部变量能准确推断时，通常不必重复标注。

## 6. 本章练习

为下面的 JavaScript 添加类型，并让错误调用被编译器发现：

```ts
function createProduct(name, price, tags) {
  return { name, price, tags, available: true };
}

createProduct("键盘", 299, ["外设", "办公"]);
```

参考方向：`name` 是字符串，`price` 是数字，`tags` 是字符串数组；返回值可以先交给编译器推断。
