# 04. 联合类型与类型收窄

## 1. 联合类型表示“多种可能”

```ts
type Id = string | number;

function normalizeId(id: Id): string {
  return String(id);
}
```

使用联合类型的值时，只能直接访问所有成员共同拥有的能力。`string` 有 `toUpperCase`，但 `number` 没有，所以必须先缩小范围。

## 2. 常用收窄方式

### `typeof`

```ts
function formatId(id: string | number): string {
  if (typeof id === "number") {
    return id.toFixed(0); // 此处分支中是 number
  }
  return id.toUpperCase(); // 排除 number 后是 string
}
```

### 真值判断

```ts
function printLength(text: string | null | undefined): void {
  if (text) {
    console.log(text.length);
  }
}
```

注意：真值判断也排除了空字符串。若空字符串是合法值，应写 `text != null`，它只排除 `null` 和 `undefined`。

### `in`

```ts
type Cat = { meow(): void };
type Dog = { bark(): void };

function speak(animal: Cat | Dog): void {
  if ("meow" in animal) animal.meow();
  else animal.bark();
}
```

### `instanceof`

```ts
function formatDate(value: Date | string): string {
  return value instanceof Date ? value.toISOString() : value;
}
```

`instanceof` 适用于运行时存在的类，不适用于 `type` 或 `interface`。

## 3. 可辨识联合：业务建模的关键模式

给联合中的每个成员添加同一个字面量字段：

```ts
type RequestState<T> =
  | { status: "idle" }
  | { status: "loading" }
  | { status: "success"; data: T }
  | { status: "error"; message: string };

function renderUsers(state: RequestState<string[]>): string {
  switch (state.status) {
    case "idle":
      return "尚未加载";
    case "loading":
      return "加载中...";
    case "success":
      return state.data.join(", ");
    case "error":
      return `加载失败：${state.message}`;
  }
}
```

这比一个包含大量可选字段的对象更安全：

```ts
// 不推荐：可能出现 success 但没有 data 的无效状态
type WeakState<T> = {
  status: "idle" | "loading" | "success" | "error";
  data?: T;
  message?: string;
};
```

好的类型模型应尽量让无效状态无法表示。

## 4. 完整性检查

新增联合成员时，希望编译器提醒所有未处理位置：

```ts
type Shape =
  | { kind: "circle"; radius: number }
  | { kind: "rectangle"; width: number; height: number };

function area(shape: Shape): number {
  switch (shape.kind) {
    case "circle":
      return Math.PI * shape.radius ** 2;
    case "rectangle":
      return shape.width * shape.height;
    default: {
      const unreachable: never = shape;
      return unreachable;
    }
  }
}
```

以后加入 `{ kind: "triangle"; ... }` 后，`shape` 在 `default` 中不再是 `never`，编译器就会报错。

## 5. 自定义类型谓词

复杂判断可以提取成类型守卫：

```ts
type User = { id: number; name: string };

function isUser(value: unknown): value is User {
  if (typeof value !== "object" || value === null) return false;
  const record = value as Record<string, unknown>;
  return typeof record.id === "number" && typeof record.name === "string";
}

const input: unknown = JSON.parse('{"id":1,"name":"小明"}');

if (isUser(input)) {
  console.log(input.name); // input 已收窄为 User
}
```

`value is User` 是类型谓词。编译器相信函数的结果，因此谓词实现必须严谨；写错不会自动得到运行时保护。复杂数据推荐使用 Zod、Valibot 等校验库生成可信结果。

## 6. 断言函数

若验证失败就抛错，可以声明断言函数：

```ts
function assertString(value: unknown): asserts value is string {
  if (typeof value !== "string") {
    throw new TypeError("期望字符串");
  }
}

function printUpper(value: unknown): void {
  assertString(value);
  console.log(value.toUpperCase());
}
```

## 7. 控制流分析

TypeScript 会跟踪赋值和提前返回：

```ts
function getLength(value: string | string[] | null): number {
  if (value === null) return 0;
  // null 已通过提前返回排除
  return value.length; // string 和 string[] 都有 length
}
```
